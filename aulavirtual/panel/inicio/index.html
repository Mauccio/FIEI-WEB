    Qué del capítulo 2 usa esta página
    • Variables con números, textos y booleanos (true o false).
    • Arrays para guardar los datos de los cursos y leerlos por posición, como courseNames[2].
    • Operadores aritméticos para los promedios, los créditos y el avance de la carrera.
    • El operador + para unir textos y armar las filas de la tabla.
    • Comentarios con // y /* */ para explicar cada bloque.
    • getElementById con textContent e innerHTML para escribir en la página, y una clase tomada de un booleano para el color, como en el ejemplo de className.
    • Tres cosas que el libro presenta más adelante: el comparador >= (compara el promedio con la nota mínima), toFixed (redondea decimales) y .length (cuenta los elementos de un array).

    Todos los nombres, códigos y notas son inventados para practicar. Para personalizar la página, cambia los valores de las variables al inicio de js/panel.js y recarga.
